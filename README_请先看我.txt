社区食堂 DID 一键部署包 - 零基础使用说明
============================================================

一、你需要把什么放在这个文件夹？

根目录建议长这样：

社区食堂_DID_项目\
│
├─ 01_一键安装环境.bat
├─ 02_检查环境.bat
├─ 03_启动Jupyter.bat
├─ 04_运行Python版.bat
├─ requirements.txt
├─ environment.yml
├─ check_env.py
├─ run_analysis.py
├─ 你的分析Notebook.ipynb
│
├─ 任意名字A.rar
├─ 任意名字B.rar
├─ 其他原始数据.rar        （如果还有，也可以继续放）
│
└─ processed\              （程序第一次运行后自动生成）

RAR 文件名完全不限。
程序会自动扫描“根目录下所有 .rar 文件”，分别解压并把其中所有 CSV 合并进入分析。

------------------------------------------------------------
二、第一次拿到一台全新的 Windows 电脑
------------------------------------------------------------

只做一件事：

    双击 01_一键安装环境.bat

然后等待。

脚本会自动：
1. 安装独立 Python 3.10 环境；
2. 使用清华 PyPI 镜像安装分析依赖；
3. 安装/注册 Jupyter；
4. 尝试安装 7-Zip；
5. 自动检查环境。

看到“环境安装成功”后即可关闭窗口。

不需要：
- 自己安装 Python；
- 自己安装 Anaconda；
- 自己输入 pip 命令；
- 自己配置 PATH；
- 翻墙。

------------------------------------------------------------
三、以后怎么运行？
------------------------------------------------------------

方式 A：Jupyter Notebook

    双击 03_启动Jupyter.bat

浏览器会自动打开 JupyterLab。
如果根目录只有一份 ipynb，会直接打开它。

方式 B：纯 Python

    双击 04_运行Python版.bat

程序会从头执行完整分析。
最终结果在：

    processed\

图形在：

    processed\figures\

------------------------------------------------------------
四、原始 RAR 怎么放？
------------------------------------------------------------

RAR 一律直接放在项目根目录。

文件名可以是任何名字，例如：

    数据1.rar
    大众点评第一批.rar
    abc.rar
    tourist_2026.rar

不需要改成 stateRes_dzdp1.rar 或 tourist_dzdp2.rar。

Python 版会：

    扫描根目录 *.rar
        ↓
    分别解压到 .cache\extracted\
        ↓
    找到所有 CSV
        ↓
    DuckDB union_by_name 合并
        ↓
    year + shop_id 去重
        ↓
    后续分析

------------------------------------------------------------
五、如果双击后失败怎么办？
------------------------------------------------------------

1. 不要立即关闭黑色窗口。
2. 截图最后 20-30 行错误信息。
3. 先双击 02_检查环境.bat。
4. 把检查结果和错误截图发给维护人员。

------------------------------------------------------------
六、磁盘空间
------------------------------------------------------------

原始数据、解压 CSV、DuckDB 数据库和临时文件都比较大。
建议项目所在磁盘至少预留 30-50 GB 可用空间。
如果数据规模继续扩大，应预留更多空间。

------------------------------------------------------------
七、整个目录可以移动吗？
------------------------------------------------------------

可以。整个项目文件夹可以整体移动到 C:\、D:\、E:\、桌面或移动硬盘。
Python 版使用“脚本所在目录”作为 ROOT，不依赖固定用户名或固定盘符。

不要只单独移动 run_analysis.py；建议整个项目目录一起移动。
